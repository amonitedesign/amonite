# 03-02 PLAN: Native Lossless Project I/O, Session Storage & File Dialog UI

## Objective
Provide Amonite CAD with full state persistence, project file backup/restoration, and an intuitive client-side import/export modal without requiring any external servers, authentication, or databases.

## Proposed Changes

### `src/lib/parsers/project-io.ts`
- Implement `createProjectJSON(nodes: CADNode[], viewport: ViewportState, title?: string): Blob`
- Implement `parseProjectJSON(jsonString: string): AmoniteProject`
- Validate schema versions (`1.0.0`) and fallback gracefully on missing fields.
- Implement `downloadBlob(blob: Blob, filename: string): void` using hidden anchor tags and `URL.revokeObjectURL`.

### `src/lib/storage.ts`
- Implement `saveWorkspaceLocally(nodes: CADNode[], viewport: ViewportState): void`
- Implement `loadWorkspaceLocally(): AmoniteProject | null`
- Implement `clearWorkspaceLocally(): void`
- Wrap all localStorage interactions in try-catch blocks to prevent QuotaExceededError crashes.

### `src/components/io/file-dialog.tsx`
- Build a tabbed modal dialog (`Export` vs `Import`) with format icons (`STL (Binary)`, `STL (ASCII)`, `AutoCAD DXF`, `SVG 2D`, `Amonite Project`).
- File upload dropzone / input handler validating extensions (`.json`, `.dxf`, `.svg`).
- Connect import handlers to `useCADStore` to add nodes or restore entire workspaces.

### `src/app/sandbox/page.tsx`
- Auto-load last saved session on mount.
- Debounced autosave (1500ms) with transient green "Saved" status pill in the top header.
- Connect File button in toolbar to trigger `FileDialog`.
