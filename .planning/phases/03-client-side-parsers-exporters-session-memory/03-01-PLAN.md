# 03-01 PLAN: Client-Side Mesh Exporters & 2D Vector Parsers

## Objective
Implement high-fidelity, client-side, zero-dependency geometry format parsers and exporters in `src/lib/parsers/` to facilitate seamless interoperability with 3D printers, CNC slicers, AutoCAD, and vector design tools.

## Proposed Changes

### `src/lib/parsers/stl-exporter.ts`
- Implement `exportToSTL(nodes: CADNode[], binary: boolean): Blob`
- For ASCII: Generate facet normals, outer loops, vertex coordinates, and solid name headers.
- For Binary: Construct an 80-byte header, 32-bit unsigned integer triangle count, and 50-byte packed triangle records (normal float32x3, vertices float32x9, attribute byte count uint16=0) using `DataView` and `ArrayBuffer`.
- Verify triangle winding order and millimeter scaling compatibility.

### `src/lib/parsers/dxf-parser.ts`
- Implement `parseDXF(dxfContent: string): [number, number][]`
- Tokenize group codes and values (code 0 entity types, code 10/20 start points, code 11/21 end points).
- Extract continuous contour paths for `LINE` and `LWPOLYLINE` entities.
- Implement `exportToDXF(nodes: CADNode[]): Blob` outputting standard R12 DXF tables and `ENTITIES` section with projection geometry.

### `src/lib/parsers/svg-parser.ts`
- Implement `parseSVGPaths(svgContent: string): [number, number][]`
- Parse XML path `d` attributes and basic `<rect>`, `<circle>`, `<polygon>` shapes into 2D polygon vertex loops.
- Implement `exportToSVG(nodes: CADNode[]): Blob` outputting standard XML SVG 2D contour projections with stroke and fill styling.
