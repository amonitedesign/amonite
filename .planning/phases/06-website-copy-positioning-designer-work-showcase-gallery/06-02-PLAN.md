# 06-02 PLAN: Illustrating Designer Work Showcase Section

## Objective
Implement an editorial, illustrating showcase section (`src/components/landing/designer-showcase.tsx`) on the landing page demonstrating actual interior decor pieces crafted in Amonite. This answers the user request: *"ADD A PROPER ILLUSTRATING SECTION TO SHOW EXMAPLES OF TH IT'S WORKS. ON DESGINERNING."*

## Showcase Archetypes Catalog

The showcase presents 4 production-grade interior decor objects with complete fabrication blueprints:

1. **Fluted Ikebana Vase**:
   - *Design Concept*: Slim neck vessel with 18 harmonic flutes inspired by Japanese minimalist ceramics.
   - *Archetype*: `fluted-vase`
   - *Dimensions*: 210 mm (H) × 95 mm (Base Ø) × 1.2 mm (Wall)
   - *Fabrication Specs*: 1h 48m print time &middot; 82g Bisque PLA &middot; 0.4mm nozzle &middot; Vase Mode (Spiralize) &middot; Watertight base
   - *Clay Shrinkage*: `+12.0%` kiln firing factor

2. **Ribbed Nordic Planter**:
   - *Design Concept*: Architectural cylindrical planter with horizontal tactile cooling ribs and integrated moisture base.
   - *Archetype*: `ribbed-planter`
   - *Dimensions*: 140 mm (H) × 160 mm (Base Ø) × 2.8 mm (Wall)
   - *Fabrication Specs*: 3h 15m print time &middot; 210g Matte Terracotta &middot; 0.6mm nozzle &middot; 3 perimeters &middot; Solid base
   - *Clay Shrinkage*: `+10.5%` stoneware factor

3. **Pleated Wave Bowl**:
   - *Design Concept*: Low-profile centerpiece fruit bowl with an undulating 12-wave pleated lip and flared stance.
   - *Archetype*: `organic-bowl`
   - *Dimensions*: 85 mm (H) × 240 mm (Rim Ø) × 1.8 mm (Wall)
   - *Fabrication Specs*: 2h 05m print time &middot; 145g Chalk White &middot; 0.4mm nozzle &middot; Continuous spiralize &middot; Zero seams
   - *Clay Shrinkage*: `+14.2%` porcelain factor

4. **Twisted Biophilic Lamp Shell**:
   - *Design Concept*: Helical lampshade with 60° rotational twist creating dynamic light dispersion when backlit.
   - *Archetype*: `twisted-lamp`
   - *Dimensions*: 260 mm (H) × 180 mm (Base Ø) × 0.8 mm (Wall)
   - *Fabrication Specs*: 2h 40m print time &middot; 115g Translucent PETG &middot; 0.8mm high-flow nozzle &middot; Vase Mode
   - *Clay Shrinkage*: `0.0%` (Additive polymer)

## Visual Design & Interaction Architecture

1. **Interactive Archetype Selector**:
   - Horizontal tab rail with quiet tactile badges: `01 // FLUTED VASE`, `02 // RIBBED PLANTER`, `03 // PLEATED BOWL`, `04 // TWISTED LAMP`.
   - Smooth active indicator highlighting selected design without loud animations.

2. **Rich Aesthetic Object Card**:
   - Render a refined visual card with dual-column presentation:
     - **Left**: Detailed architectural specification card with maker metrics (dimensions, print duration, weight, clay shrinkage badge, slicer profile tag) and a direct `"Customize in Studio"` link to `/sandbox?archetype={id}`.
     - **Right**: High-contrast visual illustration container rendering the object's parametric silhouette and contour profiles with authentic material shading (Stoneware Chalk, Terracotta Clay, Bisque White, Smoked Translucent).

3. **Mounting on Landing Page (`src/app/page.tsx`)**:
   - Insert between the Hero section and the Specification Bento section:
     ```tsx
     {/* Illustrating Designer Work Showcase */}
     <DesignerShowcase />
     ```

## Implementation Steps
