# 06-01 PLAN: Website Copy, Typography & Creator Positioning Overhaul

## Objective
Ruthlessly eliminate traditional engineering CAD jargon across the website metadata, landing page hero, and technical specification sections, pivoting Amonite's voice completely to a specialized, high-end 3D design studio for interior decorators, ceramicists, and Etsy creators (`docs/PRD-v1.0.0-amonite.md`).

## Copy & Positioning Directives

1. **Title & Metadata (`src/app/layout.tsx`)**:
   - Current: `"Amonite CAD | Browser-Based CAD/CAM Micro-SaaS"`
   - New: `"Amonite | The 3D Studio for Minimalist Interior Decor"`
   - Description: `"Procedural 3D studio for bespoke minimalist vases, ribbed planters, and ceramic decor. Instant watertight STL export for clay 3D printing, resin, and continuous vase mode."`
   - Keywords: `"3d vase studio, ceramic 3d printing, vase mode cad, clay shrinkage calculator, minimalist interior decor, parametric planter, watertight stl"`

2. **Hero Copy & Value Proposition (`src/app/page.tsx`)**:
   - Eyebrow: `"PARAMETRIC DECOR STUDIO // BESPOKE VASES & CERAMICS"`
   - Headline: `"Sculpt bespoke minimal vases & interior decor, right in your browser."`
   - Subtext: `"A dedicated digital studio for boutique makers and interior decorators. Generate infinite, print-ready variations of fluted vases, ribbed planters, and lighting shells for your Etsy shop or design client—ready for continuous extrusion, clay printing, and slip-casting."`

3. **Telemetry Metrics Overhaul (`src/app/page.tsx`)**:
   - Remove: `"Singular Brep Vessel"`, `"0 bytes leave machine"`, `"Packed 50B records for PotterBot"`
   - Introduce:
     - `PRINT RELIABILITY`: `"Guaranteed Watertight (Manifold)"`
     - `SLICING COMPATIBILITY`: `"Continuous Vase Mode (Spiralize)"`
     - `FABRICATION TOLERANCE`: `"±0.1 mm Wall Precision"`
     - `PRODUCTION TIME`: `"Direct-to-Print in Seconds"`

4. **Clay Shrinkage & Slicer Tool Spotlight (`src/app/page.tsx`)**:
   - Replace generic CAD file exchange tile with a prominent feature spotlight for the **Clay Shrinkage Tool**:
     - Visual callout illustrating 8%–15% automatic dimensional expansion compensation for wet-clay drying and bisque/glaze kiln firing.
     - Direct callout for **Continuous Vase-Mode Extrusion**: single-wall spiralize toolpaths compatible with Bambu Studio, PrusaSlicer, and Cura with zero seam artifacts.
   - De-emphasize DXF/SVG (mention as secondary mold-tracing profiles, not lead marketing points).

5. **Navigation & Footer Updates (`src/components/ui/navbar.tsx`, `src/app/page.tsx`)**:
   - Navbar subtitle: `"Minimalist 3D Decor Studio"`
   - Footer tagline: `"Procedural 3D studio for minimalist vases, vessels & bespoke interior objects."`

## Implementation Steps
1. Modify `src/app/layout.tsx`: Update `metadata` title, description, and keywords.
2. Modify `src/app/page.tsx`: Rewrite hero eyebrow, headline, subtext, metrics grid, specification bento tiles, and footer copy.
3. Modify `src/components/ui/navbar.tsx`: Ensure logo labels reflect the studio identity.
4. Update `src/app/routes.test.tsx` and `e2e/smoke.spec.ts`: Verify updated text assertions pass with 100% precision.

## Verification
- Run `npm test` to verify all route and component unit tests pass.
- Run `npx tsc --noEmit` and `npm run lint` for type safety and code quality.
