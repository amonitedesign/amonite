# 04-02 PLAN: Editorial Technical Documentation & Minimalist Early Access Funnel

## Objective
Elevate the technical documentation page (`src/app/docs/page.tsx`) into an editorial engineering manual and refine the early access waitlist modal (`src/components/landing/waitlist-modal.tsx`) into a disciplined, high-taste developer experience.

## Design Constraints & Anti-Slop Enforcements
1. **Editorial Architecture for `/docs`**:
   - Asymmetric two-column technical handbook: Sticky left-anchored index/navigation linking to sections, right-side deep technical content.
   - Distinctive typography: Monospace code headers, tabular keyboard shortcut registry with high-contrast minimal key caps (clean zinc without heavy border halos).
   - Detailed, authentic CAD domain documentation:
     - Right-Handed Cartesian coordinate system with axis vector color coding.
     - Parametric solid generation equations and triangle counts.
     - STL binary buffer format specifications (80-byte header + uint32 triangle count + 50-byte record structs).
     - AutoCAD R12 DXF group code table.
2. **Minimalist Waitlist Modal (`src/components/landing/waitlist-modal.tsx`)**:
   - Monochromatic backdrop with clean backdrop-blur (no neon sparkles or pulsating glow borders).
   - High-agency form fields with subtle focus rings and clear typography.
   - Authentic technical discipline targeting mechanical, CAM, robotics, and aerospace engineers.
   - Clean confirmation view acknowledging queueing to `amoniteadmin@gmail.com`.

## Implementation Tasks
1. **Refactor `src/app/docs/page.tsx`**:
   - Modernize layout into an editorial documentation workspace with clear hierarchy.
   - Replace generic card lists with structured technical reference tables and code snippet breakdowns.
2. **Refactor `src/components/landing/waitlist-modal.tsx`**:
   - Streamline modal layout, remove artificial gradients, and ensure accessible focus management and keyboard handling.
3. **Verify and Update Tests**:
   - Run `src/components/landing/waitlist-modal.test.tsx` and `src/app/routes.test.tsx`.
   - Verify full typecheck and build.
