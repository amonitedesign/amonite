# 05-01 PLAN: CI/CD Workflows, Repository Governance & Segregation Security Audits

## Objective
Finalize the open-source release ecosystem for Amonite CAD with robust GitHub Actions CI workflows, automated type-checking and testing gates, comprehensive documentation, and strict public-repository segregation audits.

## Proposed Changes

### CI/CD Pipelines (`.github/workflows/`)
- Maintain `.github/workflows/ci.yml` for pull requests and feature branches with fast static analysis (`npm run typecheck`, `npm run lint`), minute unit tests, and primary app tests.
- Maintain `.github/workflows/ci-main.yml` for `master` and `main` pushes covering full test coverage gates, production Next.js build bundle analysis, and automated public-repo segregation guard.
- Enforce the segregation guard regex to ensure zero auth, payment, or server database leaks.

### Governance Artifacts
- Ensure `README.md` provides accurate architecture specs, hotkey tables, quickstart commands, and official brand assets.
- Ensure `CONTRIBUTING.md` clearly states the architectural segregation invariants and PR standards.
- Ensure `CODE_OF_CONDUCT.md` and MIT `LICENSE` are present and up to date.

## Verification
- Run local segregation guard script: `git grep -iE "stripe|supabase|clerk|next-auth|prisma|drizzle|DATABASE_URL|billing|paywall|subscription" -- src/` (must return 0 matches).
- Run full test suite: `npm test` (all 19 files, 104 tests must pass).
- Run TypeScript check (`npx tsc --noEmit`) and lint (`npm run lint`).
- Run production build (`npm run build`).
