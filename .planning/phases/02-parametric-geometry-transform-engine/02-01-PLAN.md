<objective>
Implement and verify parametric solid primitives generation (Cuboid, Cylinder, Sphere, Torus, Cone, and 2D Polygon Extrusion), ensuring clean GPU buffer disposal, dynamic mesh regeneration upon parameter adjustments, and technical edge line synchronization.
</objective>

<threat_model>
- Trust Boundary: Client-side WebGL GPU buffer memory.
- Threat: Heap exhaustion or GPU memory leak from repeatedly re-generating Three.js geometries when dimensions change.
- Mitigation: Explicitly invoke `oldGeometry.dispose()` and `oldEdgesGeometry.dispose()` before re-assigning updated geometries to meshes.
</threat_model>
